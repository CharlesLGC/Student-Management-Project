# Project: Housekeeping Records of Student

### Author: Liew Guan Chern(Charles)

## Overview

> This project is a simple CRUD web application built using Spring Boot(Java, Maven) and Vue.js.
> It is used to allow users to create, read, update, search and delete student records, intergrated using MySQL database.

## Features

- Add new students through a popup form
- Edit exisiting student using a popup form
- Search student record by name or ID
- Delete student record
- View all the student records

## Technologies

- Spring Boot
- Vue.js
- MySQL
- Maven

## How to run

1. Set up database:

   > CREATE DATABSE student_db;

2. Build and Run:

   > mvn clean package
   > java -jar target/student-0.0.1-SNAPSHOT.jar

3. Visit the web page at `http://localhost:8080`
